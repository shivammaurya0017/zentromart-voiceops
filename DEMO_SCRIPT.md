# Two-minute demo recording

Use the working local app, with the document index loaded and Gnani speech enabled.
Record your screen and your own microphone. Hide all API keys; start recording only
after the password boxes have cleared. Use your own voice, not another person's.

1. Say: "This is my ZentroMart VoiceOps capstone. It answers from the supplied
   policies, remembers follow-ups, and uses Gnani for listening and speaking."
2. Click New conversation. Record: "How fast are refunds to the ZentroMart Wallet?"
3. Let the assistant answer and play its speech.
4. Record the follow-up: "What about a credit card?"
5. Let the assistant answer. Expand Evidence and tool activity briefly to show
   policy section IDs.
6. Record: "I would like a human agent, please."
7. Let the assistant create a real mock ticket and speak its handover reply. Show
   the successful create_ticket result briefly.
8. End the recording before two minutes. Save it as demo.mp4 in this project folder.

If an API error occurs, fix the problem and record a new genuine run. Do not type
or edit the agent's answers. The sample prompts above are customer inputs only;
the actual responses must come from the running system.
